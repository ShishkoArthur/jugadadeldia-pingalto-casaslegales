# PLAYBOOK — требования владельца и опыт прошлых сайтов (blackjack.cab, simsinohub, rinkmath, kenomath, gambeteo)

Собрано 02.11.2026 агентом RinkMath для **трёх аргентинских сайтов в одном репозитории** (jugadadeldia.com, pingalto.com, casaslegales.com).
Основа — PLAYBOOK gambeteo (адаптирован под Аргентину) + новое. **Главный образец для Аргентины — `/home/dev/gambeteo/`** (es-AR, ленты на
сервере без GitHub Actions, пакет помощи AR, гейты, QA); RinkMath — для киберспорта и страниц об операторах; kenomath — для лотерей.
**§1 (три продукта), §3 (доступы), §7.4 (Аргентина), §8 (язык), §17 — читать обязательно.** Остальные разделы — база.
Где написано «gambeteo» как имя проекта в разделах-базе — читать как «наш сайт»; правила те же.

## 0. Главное в двенадцати строках

1. **Числа считает код.** Ни одно число (коэффициент, вероятность, выплата, маржа, преимущество казино) не пишется руками ни в
   коде страниц, ни в текстах. Тексты получают числа метками `{{ключ}}`, сборка подставляет значения и падает, если метка не
   заполнена. Расчёты сверяются с независимым источником и тестами-«замками».
2. **Факты о мире — только с дословной цитатой** (законы, регуляторы, лицензии, телефоны помощи, возраст): пакет источников
   `data/sources/` с URL, датой и цитатой; сборка сверяет цитату побайтно с сохранённым документом.
3. **Ответственная игра в каркасе:** блок помощи на каждой странице, линии помощи со свежестью ≤ 100 дней, страницы помощи не
   ведут к игре/ставкам (даже шапкой и подвалом), нет обещаний выигрыша.
4. **Гейты по готовой сборке** (`tools/check-dist.mjs`), каждое правило доказано порчей копии (`--selftest`); красный гейт —
   выкладки нет.
5. **Тексты пишет Claude API** по заданиям на каждую страницу, с ревью и статусами `review → accepted`.
6. **Индекс открывается порциями и по слову владельца** (§9.5) — blackjack.cab после массового запуска Google понизил целиком.
7. **Доверие с первого дня:** страница автора (Denis Krazok), честно о том, как пишутся тексты, `data-nosnippet` у схем.
8. **Адреса вечные:** опубликованный URL живёт или 301 (`data/redirects.json`, только дописывать). Политику адресов — до первого языка.
9. **Мобильный — первым** (половина замечаний владельца — про телефон).
10. **Владелец решает, агент предлагает.** На вопрос — ответ и предложение; менять по слову «да/делай».
11. **HANDOFF.md всегда актуален** — проект может уйти в новый чат в любую минуту.
12. **Экономить лимиты:** генерация — через API; длинные выводы не печатать; агенты — волнами по 8–12.

## 5. Расчёты (движок проекта)

- Модуль расчётов без DOM; тот же код — в браузере (инструмент) и в Node (сборка, тесты).
- Точная математика, где возможна; Монте-Карло — только независимая проверка (ГСЧ xoshiro128**/splitmix64, не mulberry32 с
  сидами подряд — TRAPS).
- **Сверка с опубликованным источником клетка в клетку** до публикации числа. МК не ловит неверно прочитанное правило
  (Pontoon у blackjack.cab: «перевес игрока» из-за одного пропущенного правила).
- **Тест-замок** на каждый расчёт: ключевые числа зафиксированы, изменение ломает сборку и выкладку.
- **Никаких умолчаний у правил/параметров:** функция без явного набора — ошибка, а не «стандарт».
- Для беттинга: коэффициенты (американские/десятичные/дробные), маржа букмекера, no-vig, parlay, hedge, arbitrage — формулы с
  примерами из движка; «выгодная ставка» — только как математическое ожидание по введённым данным, без обещаний.
- Для реестров (казино, лицензии, лотереи): каждая запись — с источником, датой проверки и правилом свежести (как помощь — 100
  дней), гейт падает на просроченной записи; данные atlassinoca — только с разрешения владельца и только чтение.

## 6. Числа и факты
- `site/content/facts.mjs`: метка → значение из расчёта; гейт: неподставленная `{{…}}`/`[[…]]` (включая meta) — ошибка;
  «undefined», «NaN», «[object Object]» в тексте — ошибка (в simsinohub QA нашёл оба).
- Деньги в примерах — в валюте рынка (CAD), формат — `Intl` языка.
- Факты о мире: `data/sources/<lang>/<lang>.json` — `{ id, value, url, date, quote }`, документ — в `_docs/` с sha256; значение не
  говорит больше цитаты; «не нашли» — результат поиска со списком мест.

## 7. Ответственная игра и закон

### 7.1 Каркас
- Блок помощи на каждой странице (кроме страниц помощи): линии провинции/страны, кризисная линия отдельной строкой, ссылка на помощь.
- Страница помощи + самоисключение (провинциальные программы — по источникам). Номера и часы — только из пакета с цитатой;
  старше 100 дней — сборка падает.
- **Страницы помощи не ведут к игре/ставкам:** `isHelpPage` прячет игровое меню, кнопку и колонку инструментов; гейт: страница
  помощи помечена и не ссылается на страницы с игрой (решение владельца 09.10: «Да, спрячь на страницах помощи»).
- Гейт приманок (`BAIT` + `bait` языка): winning system, beat the house, guaranteed, best casino, top 10, promo code, risk-free и
  аналоги. В тексте о методе слова-приманки не перечислять — гейт ловит и их описание.

### 7.2 Тексты о законе
- Только факты с цитатами (закон, регулятор, лицензия, возраст, самоисключение). Операторов/монополистов называть по цитате, без
  ссылок (решение 05.10), если владелец не решит иначе для партнёрской модели.
- Никогда «это законно / не преступление» без цитаты закона (вопрос 13, 09.10: фраза была в 13 языках blackjack.cab — убрана).
  Формула: «ответ зависит от законов там, где вы живёте; страница не даёт юридических советов».

### 7.3 Аудитория
Взрослые пропорции персонажей, без денег/алкоголя/празднования выигрыша; возраст в подвале каждой страницы.

## 9. SEO, контент, индекс

### 9.1 Ключи (Ahrefs)
Ключ общий с simsinohub: Standard, 800 000 единиц в месяц на рабочее пространство, сброс 9-го числа. `matching-terms` ≈ 32 единицы за
строку (100 строк ≈ 3 200). Одна выгрузка на кластер × страну, сохранять в `data/keywords/`, не повторять. Голые слова с чужим
интентом проверять по выдаче («pontoon» — лодки, «martingale» — ошейники, «baccarat» — духи, «deuces wild» — фильм). Владелец:
«при создании страницы всегда ориентируйся какие ключи … есть ли там частотка», «нет задач создавать дубли страниц исключительно
ради ключей»; низкочастотные 0–10 тоже подходят, если страница полезна (simsinohub 23.10).

### 9.2 План страниц
`docs/PAGES-<LANG>.md`: страница · ключи и частотность · title · H1 · кто владеет ключом; показать владельцу страницей (артефакт).
title ≤ 60, description 115–155, один H1 по прямому интенту.

### 9.3 Тексты
- `tools/gen-text.mjs` (Opus 5.5) по заданиям; гейты: только метки вместо чисел, разрешённые теги и ссылки, приманки, запреты
  языка, длины; до 2 кругов починки; бюджет на прогон; остановка на ошибке кредита; замок на файл.
- `tools/review-text.mjs` → `docs/REVIEW-*.md`, `--fix` по ревью; статус `review → accepted`; на боевую — только accepted.
- Стиль владельца: «простым понятным языком, называй все своими именами, не надо лишних метафор … для людей которые только вошли в
  нишу … длинные полотна текста ни к чему, главное чтобы человек чисто визуально сходу уже почти все понял»; simsinohub 24.10:
  «меньше воды и текста и больше упор на наглядность» → схема в каждом разделе, ≤ 550 слов тела.
- Ошибка, найденная в одном тексте/языке, ищется во всех и правится в заданиях генератора.
- Расход: EN-страница ≈ $0,3–0,4 с ревью (simsinohub: 12 страниц ≈ $4).

### 9.4 Индексация
canonical, взаимные hreflang (+ x-default), sitemap = ровно страницы в индексе (гейт), robots.txt без запретов, og-картинка,
`speculationrules`, preload шрифта. Страницы вне индекса — `noindex,follow`, без sitemap и без hreflang на них (гейты).

### 9.5 Темп и «массовость» — урок blackjack.cab (24.10)
**Что случилось.** 1473 сгенерированные страницы за 8 дней на новом домене (23 языка, один шаблон, азартная ниша, без ссылок).
Две недели показы росли (до ~2000 в день), 17.10 позиции просели по всему сайту (35 → 50), 21.10 показы упали до 1–3 в день во
всех странах. Ручных мер нет, в индексе 1418 страниц, ошибок сканирования нет; страницы находятся по точному заголовку, но не по
запросам — автоматическое понижение всего сайта. Слабее всего — академии 22 языков (42 % сайта, 15 кликов за всё время): их
убрали из индекса, «О сайте» дополнили, схемы — `data-nosnippet`. Владелец параллельно покупает аутрич-ссылки.

**Правила:**
1. **План индекса** `data/index-plan.json` (образец — simsinohub): новая страница выходит с `noindex,follow` и вне sitemap, пока
   её адрес не внесён в план с датой; гейт check-dist. Десятки страниц в неделю, не сотни; следующая порция — когда предыдущая
   проиндексирована и не просела.
2. **Сначала основной язык;** остальные — по одному и только по слову владельца.
3. **Переводы без своего спроса — вне индекса** (`noindex,follow`); в индекс — страница, у которой на языке есть ключ и что-то
   своё (местные правила, валюта, закон).
4. **Не шаблон:** каждая индексируемая страница несёт свой инструмент/расчёт/таблицу; разные вступления и структура; своя
   иллюстрация на страницу (simsinohub: 67 сцен).
5. **Доверие** (§11.1) — до открытия индекса.
6. **Еженедельно** — Search Console владельца (выгрузку присылает он): показы по дням, средняя позиция сайта, «Просканировано, но
   не проиндексировано». Просадка по всему сайту — остановить выкладку и разбирать.

## 12. Сборка, гейты, выкладка
**Гейты** (каждый с порчей в `--selftest`): один H1 · длины title/description · canonical · og · ссылки и якоря не в никуда · `src`
существуют · `img alt` · чужая письменность вне своего языка · undefined/NaN/[object Object] · неподставленные метки · внешние
скрипты/стили · приманки и обещания сроков («coming soon») · блок помощи и `tel:` · страница помощи помечена и не ведёт к игре ·
noindex только по плану индекса · sitemap = страницы в индексе · hreflang не на страницы вне индекса · опубликованные адреса живы
или 301 · 301 не в никуда и не с живого адреса · свежесть помощи и реестров.

**`tools/deploy.sh`:** тесты расчётов → verify-rg → verify-sources → render → check-dist → tar|ssh во временный каталог → rsync
--delete → (live) 301 + Caddy validate/reload с откатом → запись опубликованных адресов (закоммитить).

**Параллельная работа:** выкладывать из чистого состояния (worktree, если агенты пишут в дерево); сборки агентов — в `dist/<имя>`
(не /tmp: tmpfs 3,7 ГБ, чистится при перезагрузке); каждому подагенту — своя подпапка scratchpad; агенты волнами по 8–12.
