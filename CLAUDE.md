# Три сайта владельца для Аргентины в одном репозитории: jugadadeldia.com · pingalto.com · casaslegales.com

**Этот файл намеренно короткий.** Он уезжает в контекст на КАЖДОМ запросе.
Решения и ловушки сюда не дописывать: их место в `docs/DECISIONS.md` и `docs/TRAPS.md`.

## С чего начинать сессию
**`HANDOFF.md` в корне** — что сделано, где остановились, следующий шаг по каждому сайту. Читать первым.
Затем **`PLAYBOOK.md`** — требования владельца и опыт прошлых сайтов (§1 — три продукта, §3 — доступы, §17 — новое после RinkMath).
Проект в любой момент может перейти в новый чат без памяти — всё важное в репозитории, не в чате.

## Что это
Один репозиторий, один чат, **три разных сайта** (решение владельца 02.11, PLAYBOOK §1), es-AR («vos»), **все пока без монетизации**:
1. **jugadadeldia.com** — кинела, лотереи Аргентины, труко и местные игры (с девушкой).
2. **pingalto.com** — киберспорт, современный дизайн, девушка «альт» лет 20 (взрослая), как можно больше игр.
3. **casaslegales.com** — обзоры букмекеров, **без девушек**, со своими скриншотами публичных страниц; без ссылок на операторов.
Каждое число считает код или стоит с цитатой. Владелец пишет по-русски и ждёт ответов по-русски.

## Чего здесь НЕ делать
- **Не трогать другие сайты и домены** на сервере 187.7.26.95 (gambeteo.com, rinkmath.com, kenomath.com, blackjack.cab, simsinohub.com,
  atlassinoar.com, atlassinoca.com, atlassino.app, casinovictoriargentina.com и любые другие) — наши только три домена выше.
  Чужие папки и репозитории не менять. Общий Caddyfile — только свои блоки, перечитывать перед записью.
- **Три сайта не должны выглядеть сетью**: свой дизайн, вёрстка, классы, структура адресов, служебные страницы и автор(ы) у каждого;
  не ссылаться друг на друга без слова владельца; имена без «math». Общим может быть только движок в коде.
- **Без монетизации и без ссылок на операторов** (владелец 02.11: «Всё пока без монетизации»). Будущая кнопка партнёрки — только по его
  слову и после юридической проверки. На pingalto — никаких ставок, кейсов и скинов (аудитория молодая).
- На вопрос владельца — ответ и предложение; менять только по его слову.
- Не печатать числа руками; не обещать выигрыш; со страниц помощи не вести к игре и ставкам.
- В отдаваемых файлах — **ни одного комментария (HTML/CSS/JS) и ни одной русской буквы**; код только на английском (гейты обязательны).
- Индекс — открыт весь (владелец 03.11); выкладка — сразу. Автор везде — Denis Krazok (03.11). Ключи только в `.env` (под игнором), значения нигде не повторять; закрытые SSH-ключи в чат не выводить.
- Не регистрироваться у операторов и не вносить деньги (скриншоты — только публичных страниц); чужие скриншоты не брать.

## Правила работы
- Коммитить в `main` по ходу без спроса; push на GitHub когда нужно. Выкладка (`deploy`-скрипты, когда появятся) — без спроса.
- HANDOFF.md обновлять и коммитить при каждой смене состояния.
- Экономить лимиты: тексты и ревью — через API (`.env`), длинные выводы не печатать; Ahrefs — считать единицы заранее (TRAPS).
- Контекст не очищать; на ~600k попросить владельца нажать /compact.
