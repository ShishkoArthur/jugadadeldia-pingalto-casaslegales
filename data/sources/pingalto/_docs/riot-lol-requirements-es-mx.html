Aquí encontrarás los requisitos del sistema para poder jugar a League of Legends en Windows y en macOS. Si tu equipo cumple únicamente los requisitos mínimos, es posible que tengas problemas de rendimiento. Ten en cuenta que el juego solo es compatible de forma nativa con macOS con procesador Intel.

Además, intentamos publicar los cambios en los requisitos mínimos con unos meses de anticipación para que todo el mundo tenga tiempo de prepararse. Esas fechas están sujetas a cambios, así que sigue consultando esta página a medida que se acerquen para obtener la información más reciente.

Requisitos del sistema para Windows

DirectX 11

Tal como anunciamos en la versión 25.02 (antes conocida como 25.T1.2),hemos actualizado los requisitos mínimos, ya que ahora el juego requiere el nivel de característica 11_00 de DirectX 11 en el caso de Windows y de Metal en el caso de Mac. A partir de la versión 25.21, deberás tener estas tecnologías de gráficos para poder seguir jugando a LoL. Si no las tienes, el botón "Jugar" estará deshabilitado y aparecerá una ventana emergente que te indicará que debes actualizar tu hardware para volver a jugar a LoL.

  • Si tu dispositivo tiene Windows 10, pero no tiene la compilación 19041 o posterior, el juego mostrará el error VAN 9004, que te indicará que actualices el sistema operativo a una versión compatible.

Ajustes de configuración mínima

Cómo usar los ajustes de configuración mínima

  • Esto REEMPLAZARÁ tu configuración actual del juego.

    ¿Qué es el archivo de configuración mínima MinConfig? Si sigues estos pasos, los ajustes del juego se adaptarán a la configuración mínima. Esto es útil cuando los ajustes actuales del juego son muy altos para que la computadora cargue una partida.

  • Descarga el archivo MinConfig.zip, que encontrarás al final de esta página.
  • Descomprime el archivo.
  • Inicia sesión en tu cuenta de League of Legends.
  • Ingresa a la carpeta "Config" (ubicación predeterminada: C:\Riot Games\League of Legends\Config).
  • Selecciona los siguientes archivos y arrástralos a la carpeta "Config": game.cfg y PersistedSettings.json.
  • Si aparece una ventana de copiar archivo, haz clic en la opción de copiar y reemplazar para ambos archivos. Si no aparece nada, ve al siguiente paso.
  • Comienza una partida personalizada. Deberías tener los ajustes de configuración mínima.

Otros sistemas operativos

League of Legends solo es compatible con Windows y macOS. No podremos ayudarte con otros sistemas operativos, como Linux, SteamOS, Bazzite, etc.
