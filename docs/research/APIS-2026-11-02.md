# Источники данных и API для автообновления трёх сайтов (ресёрч 02.11.2026)

Задача владельца (HANDOFF п. 5): «апи который необходимы для автообновления чтобы перепроверять сайты только раз в пол года».
Метод: `curl` с машины разработки (вне Аргентины, IPv6), по одному-два маленьких запроса на хост, UA без «+https://» (`jugadadeldia-feeds/1.0`,
`pingalto-feeds/1.0`, `casaslegales-check/1.0`), чтение robots.txt и условий использования. Ключи не использовались, регистраций не было,
защиту от ботов не обходили (одна попытка агента сменить UA для Mendoza отклонена правилами сессии — так и должно быть: **обход запрещён**).
Сервер 187.7.26.95 тоже вне Аргентины — гео-блоки, найденные здесь, почти наверняка действуют и там.
Статусы — на 02.11.2026. «Не проверено» — честно не подтверждено первоисточником.

Обозначения: хрупкость 1 — стабильный API, 2 — HTML/PDF с устойчивой разметкой, 3 — неофициально/меняется/может исчезнуть.

### A.5 Схема ленты кинелы
1. **LOTBA JSON** — основной (6 юрисдикций, включая Santa Fe и Mendoza).
2. **Córdoba API** — вторая независимая копия (LOTBA, PBA, Córdoba, Santa Fe, ER) + La Turista; пауза ≥ 5 с между запросами.
3. **PBA PDF** — третья копия и единственный официальный источник Montevideo; качать **1 раз после Nocturna** (5,4 МБ) + по одному днём, если нужно быстрее.
4. Сверка: тираж публикуется, только если **все доступные копии совпали до цифры**; одна копия — публикуем с пометкой источника; расхождение — стоп.
5. Свои провинции: **Tucumán JSON**, **San Juan HTML**, **Chaco HTML** (Chaco + Corrientes); Neuquén, Río Negro, La Rioja, San Luis — HTML, по одному
   разбору на сайт с фикстурой (вторая волна). Misiones (Cloudflare), Chubut (взлом/robots), IAFAS-API (токен) — не берём.
6. Quini 6 / Brinco — cas.gob.ar с проверкой «номер тиража = прошлый + 1» и даты по расписанию (ср/вс); отстаёт — честно «pendiente de publicación oficial».
7. Архив тиражей — append-only по дням (для частот 00–99 и «проверки билета»); история назад — разово из LOTBA (125 последних) и PBA по датам.

### Контракт ленты (как gambeteo)

`_health.json` по всем лентам (`stale`, `consecutiveFailures`, `lastError`).

### Проверки (validate) — что ловить
- **Кинела:** 20 номеров по 4 цифры на каждый тираж; дата и турно совпадают с запрошенными; номер тиража растёт на 1; один и тот же
  тираж из двух официальных источников (провинция + LOTBA, где LOTBA публикует чужие выписки) должен совпасть до цифры — иначе не
  публиковать. PDF → `pdftotext -layout` (poppler в образе сборки) + строгий разбор; неизвестный макет — стоп, не «догадываться».
- **Лото (Quini 6, Brinco, Loto Plus, Telekino):** количество и диапазон номеров по регламенту (Quini 6: 6 из 00–45), призы — числа ≥ 0,
  «vacante» (пул без победителей) — известное состояние, не ошибка (урок San Isidro 02.11).
- **Киберспорт:** id команд/матчей стабильны; счёт серии ≤ best-of; перенос/отмена — явные статусы (урок CFL 01.11).
- **Реестры лицензий:** разбор в нормализованный список `{ провинция, оператор, домен, лицензия }`; число записей в разумных границах
  (± 30 % от прошлого) — иначе «подозрительное изменение», данные не меняются, случай — в отчёт.

### Последние верные данные и честное скрытие
- Файл ленты заменяется только после `validate`; прошлый остаётся навсегда (история тиражей — append-only архив по дням).
- `maxAgeHours` у каждой ленты: кинела — 30 ч в будни (воскресенье и праздники — тиражей нет: календарь AR в `enabled()`/ожидаемых
  тиражах), лото — 4–8 сут по расписанию, рейтинги — 72 ч, реестры — 100 дней (как правило свежести фактов).
- Устарело → блок пишет «Datos no disponibles por el momento» + время последнего обновления; числа не показываются как свежие.

### Сигналы о сбоях (у gambeteo писем нет — TRAPS 02.11: San Isidro лежал 13 ч незамеченным)
Предложение (по слову владельца, бесплатно): **Telegram-бот владельца** — раннер шлёт одно сообщение при переходе ленты в `stale` и
при возврате (не на каждый сбой); токен бота — в `.env` на сервере. Альтернатива без аккаунтов — внешний «пульс» (healthchecks.io,
бесплатно 20 проверок): раннер пингует после удачного запуска, при тишине > N часов сервис пишет письмо. Обе — регистрация владельца.

### Ежемесячная автопроверка источников (на сервере, не в Actions)

Сюда же: **условия API** (ToS-страницы Liquipedia, PandaScore, Riot, Supercell, OpenDota) — изменение хэша = «перечитать при визите».

### Что агент проверяет раз в полгода (чек-лист — в `docs/FEEDS.md` каждого сайта)

2. Отчёт ежемесячной проверки: изменившиеся регламенты (таблица выплат кинелы, цена ставки, новые модальности Quini 6), реестры
