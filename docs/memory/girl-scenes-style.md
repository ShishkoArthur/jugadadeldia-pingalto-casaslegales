Girls: young adult women ~20–25 (state "adult, 22" in prompts), genuinely pretty, modern trendy everyday clothes (mini dresses, denim
shorts/skirts, blazer + mini, tennis skirt, alt streetwear for pingalto), no tights on pingalto. Scenes: one per page, same woman and
same outfit as the approved base, ≥ 50 % sitting or in motion (stool, chair, table edge, floor, kneeling, walking, jumping), doing
something tied to the page (shuffling cards, rolling dice mid-air, writing a scoresheet, spinning a bolillero, gaming on a controller,
talking into a headset, fist pump), modest angles, chroma key #00FF00, consistent head scale. Reference sheets:
data/img-review/contact-*-scenes-r2.jpg; jobs data/art/<site>/scene-jobs.json (r2 ids).

On pingalto, a page about a specific game must make that game recognizable in the scene (cosplay prop, pose, mood — e.g. AWP-like
sniper replica for CS2, Pudge-style hook for Dota 2, pickaxe + emote for Fortnite), never a generic phone/headset pose; no logos or
copied characters. Always count arms/hands and check the face before showing.

**Why:** owner 03.11 rejected "40-year-old" outfits and static standing scenes as boring; approved the r2 scenes: «Сцены отличные,
запиши чтобы в будущем ты всегда генерировал такого типа девушек и такого типа сцены».

**How to apply:** start every new girl/scene job from these rules and the r2 job prompts; check each image yourself (props on wrong
surfaces, glare, outfit half-on) before showing the owner. Related: [[owner-workflow]].
