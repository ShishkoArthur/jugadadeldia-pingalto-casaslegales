## Поиск и индекс
- **Массовый запуск → Google понижает весь сайт** (blackjack.cab, 21.10): 1473 сгенерированные страницы за 8 дней на новом домене →
  через две недели показы с ~1300 до 1–3 в день, без ручных мер и ошибок сканирования, страницы в индексе. Техникой не лечится.
  Правила — PLAYBOOK §9.5. Признак: страница находится по точному заголовку, но не по запросам.
- **Цифры брифа устаревают** (simsinohub 23.10): «roulette simulator» KD 0 в брифе 30.09 → KD 55 в Ahrefs 23.10. Решать по свежей выгрузке.
- **Голые ключевые слова с чужим интентом:** pontoon (лодки), spanish 21 (страны), martingale (ошейники), baccarat (духи), iron cross,
  dragon 7 (игры), deuces wild (фильм).
- **Гейт приманок ловит и описание приманок** в тексте о методе — слова-приманки там не перечислять.
- **Ошибочная фраза в одном языке есть и в других** и в заданиях генератора — искать везде, править задания.

## Окружение и выкладка
- **/tmp — tmpfs ~3,7 ГБ** и чистится при перезагрузке: сборки — в `dist/<имя>`; временный worktree выкладки пропадает.
- **Scratchpad общий для всех подагентов** — каждому своя подпапка.
- **Выкладка, пока агенты пишут в дерево**, захватит их незаконченные файлы — выкладывать из чистого worktree.
- **Caddy общий с чужими сайтами:** только свой блок, бэкап → validate → reload → соседи 200; каталог не подменять `mv`.
- **Deploy key GitHub — один репозиторий;** новому репозиторию — новый ключ (для этого проекта создан `~/.ssh/canadabetting_ed25519`).
- **Cloudflare-токен** видит только выданные зоны (27.10: blackjack.cab, simsinohub.com), только DNS; Turnstile и Pages — нет прав.
- **Cloudflare Email Obfuscation** — body в `<!--email_off-->…<!--/email_off-->`.
- **Ключи в `.env` blackjackcab устарели** (27.10): Ahrefs — 401, Nano Banana — 4 кредита. Рабочий набор — из simsinohub (скопирован сюда).
- **Классификатор авто-режима** в simsinohub блокировал копирование `.env` и `ssh-keygen` — если понадобится снова, команды даёт владельцу.
- **`pkill -f <строка>`** убивает и собственную оболочку — искать PID через `ps` и убивать по номеру.

## Вёрстка
- **`overflow:hidden` у предка выключает `position:sticky`** молча — обрезать `overflow:clip` (после `hidden`).
- **Полноэкранный режим Android:** системная плашка ~30 с закрывает низ — полоса 56–96 px снизу на сенсорных экранах.
- **Отступы `.tool{padding:…}`** обнуляли боковые поля — только `padding-top`.
- **Персонаж в разных позах в разном масштабе** — мерить голову, приводить к медиане.
- **Длинный список языков** уходил за экран — колонки, на телефоне в пределах экрана.
- **`requestAnimationFrame` в скрытой вкладке не идёт** — запасной таймер у каждой анимации (simsinohub: спин не завершался).

## gambeteo
- **01.11 — ленты на сервере падали EACCES после выкладки.** Симптом: `feeds-server.sh status` → `EACCES /out/_health.json.tmp-1`, `_health.json`
  застыл. Причина: `deploy.sh` (и пересборка) делают `rsync -a` каталога сайта; защищённый фильтром `data/feeds/` сохраняет файлы, но **атрибуты
  самого каталога** приходят из сборки (uid 1001, 775), а контейнер лент пишет как uid 47100. Правило: раннер лент перед каждым запуском делает
  `chown 47100 data/feeds` (`tools/feeds-server.sh`); любой новый писатель в каталог сайта — проверять владельцев.
- **01.11 — агенты в общем дереве.** Полусделанные файлы одного агента ломают сборку остальным; агенты, работающие в `dist/wt-builder`, коммитят
  в ветку worktree, а не в main (переносить cherry-pick). Правило: выкладка — только из чистого worktree (`git checkout -B deploy origin/main`),
  у каждого агента своя папка сборки `OUT=dist/<имя>`; `feeds-server.sh sync` из грязного дерева увозит на сервер незакоммиченные ленты.
- **01.11 — неподтверждённый день матча.** ESPN без подтверждённого времени ставит весь тур на один день; показывать «fin de semana del …

  есть только в новом сервисе FIFA (id `FRS_Male_Football_…`). Лента `seleccion` ищет новейшую публикацию на странице рейтинга и падает
  на старый API только при расхождении. Признак: «дата рейтинга» перестала меняться месяцами.
