# Английская версия сайта (`/en/…`) — как устроено и как добавить её сайту

Решение владельца 04.11 (DECISIONS): у каждого сайта английская версия **для аргентинцев** — та же аргентинская суть (провинции, песо,
hora argentina, местные линии помощи), перевод через Claude API с глоссарием и ревью, взаимные hreflang + x-default = es, индекс открыт,
у каждого сайта своя схема адресов `/en/…`. Первый сайт — **jugadadeldia** (04.11). По этому файлу то же делают pingalto и casaslegales.

## 1. Как устроено (общий движок, ничего сайтового)
- **Испанский код страниц не трогаем.** Сборка (`tools/render.mjs`) рисует каждую страницу второй раз «в английском проходе»:
  `h.lang = 'en'`, `h.site.htmlLang = 'en'`, `h.site.ogLocale = 'en_US'`, title/description/H1 — английские из плана
  (`data/plan/<сайт>.json`: `urlEn`, `titleEn`, `descriptionEn`, `h1En`). **Путь страницы в проходе остаётся испанским** (`h.page.path`) —
  поэтому сцены, данные, `aria-current` в меню работают как есть; `h.page.enPath` — английский адрес.
- Готовый HTML проходит `htmlToEn()` (`tools/lib/i18n.mjs`): каждый кусок текста между блочными тегами (строчные теги — маркеры
  `<t1>…</t1>`, `<t2/>`), атрибуты `alt`/`title`/`aria-label`/`placeholder`/`value` текстовых полей, строки JSON-LD (`name`, `text`, …;
  `inLanguage` → `en`), ссылки → английские адреса, canonical и og:url → английские. Куски, состоящие из целых элементов (меню, плитки,
  строки таблиц), режутся по элементу — одна короткая строка на подпись.
- **Где берётся английский:** сначала словарь сайта `sites/<сайт>/i18n/en.mjs` (`export const UI = { 'испанская строка': 'English' }` —
  меню, шапка, подвал, блок помощи; он главнее памяти), потом **память перевода** `data/i18n/<сайт>-en.json` (`text` — страницы,
  `code` — строки браузерных модулей, ключ `файл :: строка`). Сборка **никогда не зовёт API**: нет строки → сборка падает со списком
  (`English: N strings are not in data/i18n/…`) → `node tools/translate.mjs <сайт>`.
- **Числа и даты — слоты `{1}`, `{2}`:** в ключе памяти цифры заменены слотами («Del {1} al {2}» → «From {1} to {2}»), значения
  подставляет сборка. Поэтому новая дата проверки или другой счётчик **не требуют перевода**, а перевод не может поменять число
  (гейт переводчика: те же слоты, ни одной своей цифры).
- **Браузерные модули** (`client/*.js` + модули движка, которые они импортируют) собираются второй раз: строковые литералы, которые могут
  быть видимым текстом, заменяются из памяти (`codeToEn`), пути страниц в строках → `/en/…`; у английских модулей свои файлы (хеш),
  английская страница грузит их (`h.asset` в проходе). Литералы в позициях кода (импорты, ключи объектов, сравнения `===`, `case`,
  селекторы, `setAttribute`/`store` первым аргументом, `className`, `dataset`) не трогаются; остальное модель возвращает без изменений,
  если это код. После замены модуль парсится (acorn) — синтаксис не ломается.
- **Числа в браузере:** `engine/games/num.mjs` смотрит `<html lang>`: на `en` — «1,234.5», «55%»; на испанских страницах и в Node — как было.
- **hreflang:** сборка сама ставит в `<head>` обеих версий `es-AR`, `en`, `x-default` (= испанская); sitemap — все страницы обоих языков
  с `xhtml:link` (3 на пару). Страница без английской версии — без hreflang.
- **Переключатель языка** рисует layout сайта (свой вид): `h.langs()` → `[{ lang, code, label, href, current }]` (пусто без пары). Ссылка
  обязана нести `hreflang` (так её узнают гейт и переводчик) и `translate="no"` (подпись не переводится).
- **Цитаты официальных документов** (`<blockquote>`) остаются испанскими (`lang="es-AR"`, это доказательство), сразу после — английский
  пересказ через `SITE.i18n.quoteNote(html)` (на jugadadeldia `<p class="jg-qtr">In English: …</p>`).
- **404** — одна, испанская (Caddy отдаёт `/404.html` на любой адрес).

## 2. Форматы английской версии (одинаково на трёх сайтах)
| Что | es-AR | en |
|---|---|---|
| деньги | `$ 1.234,50` | `$ 1,234.50` (песо; «$», пробел, английские разделители; в долларах не пересчитываем) |
| дробь, проценты | `2,5` · `40,0 %` | `2.5` · `40.0%` |
| дата | `04/11/2026` | `4 Nov 2026` (в виджетах кратко день/месяц — как в Аргентине) |
| время | `21:00`, hora argentina | `21:00`, Argentina time (24 часа, как в программах лотерей) |
| номера законов | `Ley 15.079` | `Ley 15.079` (официальная запись не меняется) |
Перевод чисел делает код (`numEn`), не модель.

## 3. Гейты (`tools/check-dist.mjs` → `tools/lib/i18n-check.mjs`, все в selftest)
`hreflang` (ровно es-AR/en/x-default, цели существуют и взаимны, sitemap — 3 alternates) · `langlink` (английская страница ссылается
только на английские, испанская — только на испанские; ссылки с hreflang — исключение) · `langswitch` (у пары есть ссылка-переключатель) ·
`spanish` (на английской странице остались испанские слова; не считаются: имена из `keep` глоссария, `SITE.i18n.allow`, цитаты,
элементы `lang="es…"` и `translate="no"`) · `decimal` (десятичная запятая на английской) · `oglocale` · `langattr` (`en` / `es-AR`) ·
`urlscheme` (`/en` + своя схема сайта). Остальные гейты (title ≤ 60, description 115–155, один H1, canonical, og, блок помощи + `tel:` +
18+, страницы помощи без меню, приманки EN/ES, кириллица, комментарии, вес) действуют и на английских страницах.

## 4. Как добавить английский сайту (pingalto, casaslegales) — по шагам
1. **config.mjs:** `langs: ['es', 'en']`; `i18n: { quoteNote: en => '<p class="<префикс>-…" lang="en">…</p>', allow: [...] }` (allow —
   свои имена, которые остаются по-испански; цитат нет — `quoteNote` можно не задавать, тогда blockquote переводится как текст).
   Проверить, что `fileOf('/en/…')` даёт правильный файл и что `/en/…` проходит `sitePath` (`/en` + своя схема: casaslegales — без слэша,
   главная `/en`; pingalto — свой редирект слэша в Caddy).
2. **layout.mjs:** переключатель в шапке (`h.langs()`, свой стиль, `hreflang` + `translate="no"`); строки, которые layout кладёт в JSON
   для браузера, — через `h.tr('…')`; `h.lang` — язык прохода (поиск, данные). Ничего не переводить в коде страниц.
3. **`sites/<сайт>/i18n/en.mjs`** — `UI`: подписи меню (меню строится из плана/страниц), шапка, подвал, блок помощи. Точная испанская
   строка как в HTML (после склейки), числа как `{1}`.
4. **`data/i18n/<сайт>-glossary.json`** — `audience`, `money`, `time`, `keep` (имена: игры, турниры, провинции, регуляторы, бренды),
   `terms` (местные слова с короткой расшифровкой), `urlRule` (как `--meta` пишет английские адреса своей схемы; без него — правило
   jugadadeldia со слэшем). Образец — `jugadadeldia-glossary.json`, схема без слэша — `pingalto-glossary.json` (главная `/en`).
5. `node tools/translate.mjs <сайт> --meta` — Sonnet 5.5 пишет `urlEn/titleEn/descriptionEn/h1En` в план (длины проверяет код, 3 круга);
   **просмотреть глазами** (адреса — английские слова + аргентинские названия; title — под английский поиск, ≤ 60) и поправить руками.
6. `node tools/translate.mjs <сайт> [--budget=15]` — все строки, которых нет в памяти (страницы пачками по странице, потом модули).
   Ответ проверяется (маркеры, слоты, теги и пробелы в строках кода, кириллица), один круг починки, отказ — в лог; повторный запуск
   доделывает. Расход — `data/i18n/_spend.json`.
7. `node tools/render.mjs <сайт>` → `node tools/check-dist.mjs <сайт>` → `--selftest` (чинить `spanish`: перевести строку в памяти/словаре
   или добавить имя в `keep`).
8. Ревью: `node tools/translate.mjs <сайт> --review=6 --apply` — Opus 5.5 читает по странице каждого типа (испанская против английской),
   пишет `docs/REVIEW-EN-<сайт>.md`, `--apply` вносит исправления, которые проходят проверку; остальное — руками в памяти.
9. Живьём: `/en/` и 5 страниц на 375/1280 (инструменты, ленты, игры — тексты из браузерных модулей видны только так), hreflang.
10. Коммит: план, память, глоссарий, `i18n/en.mjs`, config/layout/css → `bash tools/deploy.sh <сайт>`.

## 5. Обслуживание
- Изменили испанский текст страницы → сборка английской упадёт со списком строк → `node tools/translate.mjs <сайт>` (центы) → коммит памяти.
  Старые записи памяти не мешают (их можно чистить, но не обязательно).
- Новая страница: строка плана с `urlEn…` (`--meta` дописывает только недостающие) → `translate` → сборка. Без строки плана страница
  просто не получает английской версии и hreflang.
- Стоимость jugadadeldia (04.11): см. HANDOFF (план ≈ $0,25, строки ≈ $2–3, ревью ≈ $0,5).

## 6. Ловушки
- **Строка-ключ в браузерном модуле.** Если литерал — значение, которое где-то сравнивается или служит ключом, а модель его перевела,
  инструмент сломается только на `/en/`. Защита: позиции кода пропускаются, одиночные слова, встречающиеся в позициях кода, — тоже;
  но проверять инструменты на английских страницах живьём обязательно. Исправление — в памяти (`code`): значение = исходной строке.
- **Склейка фрагментов** (`'Línea ' + free + 'de ' + name`) переводится по кусочкам — порядок слов английского бывает кривым; править
  в памяти соседние куски вместе или перевести целую фразу в layout через `h.tr`.
- Испанский в атрибутах `data-*` и в JSON лент (`/data/feeds/*.json`: имена турно, юрисдикций) не переводится — это имена (Nocturna,
  Ciudad, Provincia), они в `keep`.
- Чужие незакоммиченные правки в общих файлах (`render.mjs`, `check-dist.mjs`, layout): коммитить только свои куски
  (`git apply --cached` своего патча), перечитывать файл перед записью.
