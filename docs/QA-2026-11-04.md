## Как повторить
```
node tools/qa/live-pass.cjs --site <сайт> --workers 2 --out <папка>      # ~25–45 мин на сайт; --paths /a,/b для перепроверки
node tools/qa/summary.cjs <папка>/results.json
node tools/qa/links.cjs <сайт>
node tools/render.mjs <сайт> && node tools/qa/static.mjs <сайт> [--probe 5]   # sitemap сравнивается со свежей сборкой dist/<сайт>
```
Локально с живыми лентами: простой сервер, который отдаёт `dist/<сайт>` и проксирует `/data/feeds/*` на живой сайт (`.mjs` —
`text/javascript`), затем `live-pass.cjs --base http://localhost:<порт>`.
