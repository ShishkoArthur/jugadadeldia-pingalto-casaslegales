3. Ошибки в числах

Проверено независимо (свой код, не движок сайта) и в браузере:

  • Сенса: CS2 1,25 @ 800 DPI → Valorant 1,25 × 0,022 / 0,07 = 0,393 ✓; см/360 = 360 / (800/2,54 × 1,25 × 0,022) = 41,6 ✓; eDPI 1 000 / 314 ✓; яу 0,022 (исходник Valve SDK) / 0,07 / 0,0066 ✓, Apex = 0,022 ✓.
  • DPI: счётчики / (мм / 25,4); SUBE 85,6 мм (ISO 7810 ID-1) ✓.
  • Пинг-пол: 2 × d / (c / 1,4475): CABA→Сантьяго ≈ 11 мс, São Paulo ≈ 16, Майами ≈ 69 ✓ (гаверсинус, R = 6371,0088).
  • Серии Bo1–Bo7: ДП движка против закрытой формулы Σ C(w−1+j, j) pʷ qʲ — расхождение 0; Bo5 при 1–2 и p = 0,6 → 0,36 ✓; обратная задача (75 % за Bo3 → 67,4 % за карту) ✓.
  • Швейцарка (Bo3 в матчах на выход/вылет): точный расчёт против 400 000 прогонов Монте-Карло: p = 0,5 → проход 0,4986 / 0,5; p = 0,6 → 0,7199 / 0,7208 ✓; распределение 3-0…0-3 совпадает до 0,002.
  • VRS: E = 1/(1+10^(−g·Δ/400)), g(RD 75) = 0,9728; 100 очков → 63,65 % ✓; 60 % ↔ 72 очка ✓; живой пример Aurora–9z (370 очков) 88,8 % и 79,2 % за карту Bo3 ✓.
  • Облако: 10 Мбит/с → 4,5 ГБ/ч ✓. Уилсон 50/100 → 40,4–59,6 % ✓. Прицел CS2: кодирование ↔ декодирование без потерь ✓.
  • Новое: загрузка CS2 85 ГБ × 8000 / Мбит/с: 50 → 3,8 ч, 300 → 38 мин ✓.

Ошибок в расчётах не найдено. Найдено и исправлено в тексте: плитка главной звала /cs2 «Ranking» (теперь «¿Te corre CS2?»), ссылки «ranking de CS2» ведут на /cs2#ranking, «1 GB libres» → «libre».

5. Сравнение с blackjack.cab (/es/)

У blackjack.cab: одно ключевое число на первом экране, единый метод для всех инструментов, академия коротких уроков («¿Cómo se juega?», правила, глоссарий, уроки с практикой и вопросами) и чёткая навигация «Aprende a jugar». У pingalto инструменты сильнее и разнообразнее (ленты, симуляторы, источники с цитатами), но не хватало ответов «cómo» на уровне игры — теперь есть у CS2, Fortnite, Free Fire; нет у LoL, Valorant, Dota 2, Clash, Brawl, RL. Глоссария esports нет.
